# 🚨 AI Hype Detector

**Paste any text to see how much AI buzzword BS it contains**

A fun tool that analyzes text for AI buzzwords, startup clichés, and corporate speak to give you a "hype score" from 0-100%.

## Features

- **Real-time analysis** of AI buzzwords and corporate speak
- **Hype score** from 0-100% based on buzzword density and type
- **Breakdown by category** (Hyperbole, Tech Speak, Corporate Speak, etc.)
- **Visual feedback** with color-coded scores
- **Example text** for quick testing

## Try it live

🌐 **[ai-hype-detector.vercel.app](https://ai-hype-detector.vercel.app)**

## How it works

The detector analyzes text for:

### High-Impact Buzzwords (15-20 points each)
- "Revolutionary", "groundbreaking", "disruptive"
- "Ninja", "rockstar", "10x", "unicorn"
- "Infinite", "unprecedented", "paradigm"

### Medium-Impact Terms (8-12 points each)
- "AI-powered", "next-generation", "cutting-edge"
- "Synergy", "leverage", "optimize"
- "Transform", "disrupt", "innovate"

### Standard Tech Terms (6-8 points each)
- "Machine learning", "blockchain", "quantum"
- "Proprietary", "enterprise-grade", "scalable"

## Scoring

- **0-20%**: ✅ Refreshingly honest!
- **21-45%**: ⚠️ Moderate hype levels
- **46-70%**: 🚨 High hype alert!
- **71-100%**: 💀 EXTREME HYPE!

## Examples

**Low Hype (12%)**:
> "We built a Python script that analyzes customer support tickets and suggests relevant help articles. It uses basic NLP to match keywords and has reduced response time by 30%."

**Extreme Hype (94%)**:
> "We're revolutionizing the AI landscape with our groundbreaking, next-generation machine learning platform that leverages cutting-edge neural networks to deliver unprecedented, game-changing results."
